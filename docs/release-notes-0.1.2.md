# VOICEog 0.1.2

**Дата:** 2026-09-27 · **Тип:** patch (мелкие исправления, без новых функций)

Windows-сборка догоняет Linux по мелочам: установщик больше не выдаёт кракозябры,
второй клик по `.exe` поднимает уже открытое окно, а не плодит второе, и мышь по
трею ведёт себя как положено.

---

## Главное: установщик говорит по-русски

- **Было:** в установщике вместо русского текста — кракозябры (мусорные символы).
- **Причина:** файл `.nsi` лежал в **UTF-8 без объявления кодировки**, а
  `makensis` на Windows-раннере читал исходник в **системной однобайтовой
  кодировке** (OEM/ACP). UTF-8 байты он толковал как ANSI — отсюда мусор.
- **Стало:** первой строкой `.nsi` стоит маркер `# -*- coding: utf-8 -*-`, а
  сборка передаёт `makensis` флаг `-INPUTCHARSET UTF8`. Теперь кодировка задана
  явно и от системной локали раннера не зависит. Русский текст — как надо.

---

## Одиночный запуск на Windows

- **Было:** клик по `.exe`, когда приложение уже работало, плодил **второй
  экземпляр** — или не поднимал уже открытое окно (оно оставалось спрятанным в
  трее).
- **Стало:** окно опознаёт себя через **named mutex + named event**. Второй
  запуск не создаёт новое окно, а посылает сигнал первому: тот **показывает и
  фокусирует** уже открытое окно, а второй процесс сразу выходит.
- **Ярлык тоже умеет.** `launch.vbs` при живом окне не запускает ещё одно, а
  поднимает существующее — то же поведение, что и при клике по `.exe`.
- На Linux — без изменений: там за это отвечает D-Bus (разбор — в
  `docs/troubleshooting.md`, раздел «Про single-instance»).

---

## Мышь по трею на Windows

- **Левый клик** — показать/скрыть окно.
- **Правый клик** — меню трея.
- На Linux поведение прежнее.

---

## Лончеры

- **`launch.vbs` пересохранён в UTF-16LE.** WSH (Windows Script Host) не умеет
  UTF-8: с ним `MsgBox` и прочие строки выводились кракозябрами. UTF-16LE (или
  ANSI) — родной формат для `.vbs`.
- **`voiceog-console.cmd` получил `chcp 65001`** — консоль переключается в
  UTF-8, чтобы русский текст в логах читался, а не превращался в кашу.
