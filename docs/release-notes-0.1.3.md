# VOICEog 0.1.3

**Дата:** 2026-09-28 · **Тип:** patch (мелкие исправления, без новых функций)

Косметика для Windows, которая на деле бьёт по доверию к программе: окно и
панель задач больше не показывают дефолтную иконку, а сам `.exe` в Проводнике
выглядит как наш микрофон, а не как безымянный бинарь.

---

## Иконка окна на Windows

- **Было:** окно и панель задач рисовали дефолтную иконку. Иконку окна никто не
  задавал, и Windows показывал что попало (на Linux её подхватывал GTK из
  `.desktop`-файла, поэтому там было нормально).
- **Стало:** в окно ставим **тот же микрофон**, что и в трее, через
  `with_window_icon`:
  - **маленькая** иконка (`IconType::Small`) — в заголовок окна (`window_icon(64)`);
  - **большая** (`IconType::Big`) — панель задач и Alt+Tab. На Windows её
    задаём отдельно через `with_taskbar_icon` (`window_icon(256)`), потому что
    общий `with_window_icon` до панели задач не достаёт — он ставит только
    маленькую. Импорт трейта — строго под `#[cfg(windows)]`, чтобы Linux и
    кросс-сборка не ломались.
- На Linux — без изменений: иконку рабочего стола и панели по-прежнему берут из
  `.desktop`.

---

## Иконка файла `.exe`

- **Было:** `voiceog-window.exe` в Проводнике показывался дефолтным значком
  приложения.
- **Стало:** на этапе сборки вшиваем `window/packaging/windows/app.ico` (тот же
  микрофон) прямо в `voiceog-window.exe` через `build.rs`. Проводник, ярлык и
  «Свойства → ярлык» теперь показывают нашу иконку, а не системную заглушку.

---

## Обновление

- **Linux** — `.rpm` / `.deb` / `.AppImage` / `tar.zst`, как обычно.
- **Windows** — `VOICEog-setup.exe`.

Ставится поверх старой версии, данные и настройки не трогаются.
