# Дизайн морды: откуда взяты токены

Морда VOICEog (`public/index.html`) оформлена в стиле **Vercel Geist**
(страница `designsystems.one/design-systems/vercel-geist`). Значения сняты не на
глаз, а из палитры системы: `#000000`, `#ededed`, `#0070f3`, `#333333`,
`#ffffff`, `#666666`, `#eaeaea`, `#fafafa`, `#ee0000`.

Суть Geist — **монохром**: почти без цвета, глубина за счёт оттенков серого и
тонких рамок. Единственный цветной акцент — синий `#0070f3` (ссылки, фокус,
активные бейджи). Никаких градиентов и свечения.

## Палитра (светлая / тёмная)

Тема переключается через `color-scheme`, значения лежат в `light-dark(светлая,
тёмная)` — без дублирования правил.

| Токен | Светлая | Тёмная | Что это |
|---|---|---|---|
| `--bg` | `#fafafa` | `#000000` | фон страницы |
| `--panel` | `#ffffff` | `#0a0a0a` | карточка |
| `--line` | `#eaeaea` | `#333333` | рамка |
| `--line-2` | `#d4d4d4` | `#444444` | рамка кнопок/полей |
| `--text` | `#000000` | `#ededed` | текст |
| `--muted` | `#666666` | `#888888` | приглушённый текст |
| `--brand` | `#f0f0f0` | `#151515` | кнопка записи: тихая поверхность (не заливка) |
| `--brand-fg` | `#1a1a1a` | `#e8e8e8` | текст на кнопке |
| `--accent` | `#0070f3` | `#0070f3` | единственный цвет (ссылки, фокус, «ok») |
| `--accent-soft` | `#eaf4ff` | `#0a2a4d` | мягкая подложка фокуса |
| `--danger` | `#ee0000` | `#ee0000` | ошибка, точка записи |

Формы: карточка — радиус **8px**, тень почти незаметная (`0 1px 2px rgba(0,0,0,.04)`);
кнопки, поля, бейджи — радиус **6px**. Пилюль и крупных теней нет — это не стиль Geist.
Главная кнопка записи — намеренно **не контрастная**: светло-серая поверхность на
светлой теме, тёмно-серая на тёмной, с тонкой рамкой. Раньше она была заливкой
(чёрной/белой) и била по глазам; теперь это спокойный блок, а заметная она за счёт
размера. Красная точка — единственный «сигнал» (идёт запись); при записи рамка
кнопки краснеет.

## Шрифт — и тонкость

В Geist шрифты называются Geist Sans / Geist Mono. Кириллицу мы гарантировать не
можем, поэтому стек такой:
```
--sans: "Geist", "Inter", ui-sans-serif, system-ui, ...;
--mono: "Geist Mono", "JetBrains Mono", ui-monospace, ...;
```
Латиница — Geist (как в системе), кириллица — Inter (у него она есть) или
системный шрифт. Поле распознанного текста оставлено моноширинным — читается как
«вывод», а не как украшение.

## Где менять

Всё — в одном блоке `:root` в начале `<style>` внутри `public/index.html`.
Поменял переменную — поменялось везде. Сборщиков нет: сервер читает файл на
каждый запрос, перезапуск не нужен.

## Границы

- Шрифты **не вшиты** — берутся из системы, если есть. Хочешь гарантированно
  Geist — положи `.woff2` в `public/fonts/` и научи сервер отдавать их (сейчас
  он отдаёт только саму страницу).
- Дизайн — только внешний вид. Логика (хоткей, запись, вставка, доктор) не
  затронута.
